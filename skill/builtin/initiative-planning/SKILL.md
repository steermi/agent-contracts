# Initiative planning

Break an initiative into the work each team owns.

- Read the initiative, its brief and the work already in it before proposing.
- Propose one epic per team that has a real part in the outcome, in that
  team's project, with a short description and acceptance in plain words.
- Name cross-team dependencies explicitly (which epic blocks which) and keep
  them few.
- Reuse epics that already exist instead of duplicating them.
- Never create or change work yourself; a person reviews and applies the plan.
