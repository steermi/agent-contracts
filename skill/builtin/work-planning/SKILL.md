# Research

Research and plan the stated goal using the selected project sources.

- Capture decisions, alternatives and uncertainty.
- Propose delivery work only when it helps; a saved report with no tickets is
  a valid outcome.
- When proposed work has an order, record it as dependencies (an item is
  blocked by the work it needs first) and search for existing items that
  already cover a step before proposing a duplicate.
